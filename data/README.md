# Data

`project2_data.csv` — trial data for the Mali water-intervention study: 214 observations
(107 students × 2 visits: control day and water-intervention day), 52 columns covering
cognitive test scores (LCS, NRC, …), hydration measures, and demographics.

`codebook.csv` — variable labels for the dataset.

The data is committed directly (small file). Source: course-provided dataset for the
INF2178 capstone; the original file also shipped a data dictionary sheet, preserved here
as `codebook.csv`.
